# Scan and read a finding

A scan (automatic, or **PatchAI: Scan Workspace for Vulnerabilities**) shows each finding in four places:

- a **squiggly underline** in the code
- the **Problems panel** (the CWE id links to its official description)
- the **PatchAI side bar**, grouped by file
- the **status bar**: "PatchAI: 7 issues"

Hover over an underlined line to read **what an attacker could do** and to jump straight to the fix.
