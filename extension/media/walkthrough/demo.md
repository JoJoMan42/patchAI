# Open the demo project

**PatchAI: Open Demo Project** opens a small online shop with **seven deliberate security holes** — one of each type PatchAI handles: SQL injection, command injection, path traversal, XSS, a hard-coded secret, weak cryptography and unsafe deserialization.

It is a **scratch copy**: fix and break as much as you like, the original is never touched. Running the command again resets the copy.

The new window scans automatically and the findings appear within a few seconds.
